# 영어 타자 게임

소리를 듣고 영어 문장을 따라 치는 게임이에요. 화면을 보지 않고 소리와 키보드만으로 할 수 있게 만들었고, 화면 낭독 프로그램과 함께 쓸 수 있어요.

## 하는 법
1. **시작하기**를 누르면 단축키 안내를 듣고 문장을 들을 수 있어요.
2. 문장을 듣고 한 글자씩 따라 쳐요. 맞으면 소리가 점점 높아지고, 틀리면 "땡~" 소리가 나며 높이가 처음으로 돌아가요.
3. 글자 하나를 맞힐 때마다 10점이에요. 5개, 10개 콤보마다 알려 줘요.
4. 문장을 듣고 나서부터 시간을 재요. 10초 안에 끝내면 +50점, 20초 안에 끝내면 +30점이에요.
5. 한 판은 문장 10개예요. 끝나면 결과를 듣고 이름을 입력해서 점수를 저장해요.

## 단축키
| 키 | 하는 일 |
|---|---|
| 엔터 | 다음 문장 (한 판이 끝나면 결과 보기) |
| 백스페이스 | 글자 지우기 |
| 이에스씨 (Esc) | 문장 다시 듣기 |
| 컨트롤 + 좌우 화살표 | 예시 문장을 한 글자씩 읽기 |
| 좌우 화살표 | 내가 친 글자를 커서 따라 읽기 |
| 에프파이브 (F5) | 말하기 빠르게 (최대 2배) |
| 에프식스 (F6) | 말하기 느리게 (최소 0.8배) |
| 에프포 (F4) | 지금까지 쓴 글자 읽기 |
| 에프쓰리 (F3) | 소리 멈추기 |
| 에프세븐 (F7) | 배경음악 켜기와 끄기 (기본은 꺼짐) |
| 에프나인 (F9) | 단축키 안내를 항목별로 듣기 |

## 점수판 설정 (구글 시트 + Apps Script)

점수는 구글 시트에 저장돼요. 집 PC는 열지 않아요.

### 1단계: 구글 시트 만들기
1. 구글 드라이브에서 **새 스프레드시트**를 만들어요. 이름은 "영어타자 점수판"처럼 정하면 돼요.
2. 메뉴에서 **확장 프로그램 → Apps Script**를 눌러요.

### 2단계: 코드 붙여 넣기
1. Apps Script 편집기에 있는 기본 코드를 모두 지워요.
2. 이 저장소의 `score-server/Code.gs` 내용을 전부 붙여 넣어요.
3. 저장(디스크 아이콘)을 눌러요.

### 3단계: 웹앱으로 배포하기
1. 오른쪽 위 **배포 → 새 배포**를 눌러요.
2. 종류는 **웹 앱**을 선택해요.
3. 실행 사용자: **나**
4. 액세스 권한: **모든 사용자** (게임 페이지가 로그인 없이 점수를 읽고 쓰려면 필요해요)
5. **배포**를 누르고 나온 **웹 앱 URL**을 복사해요. `https://script.google.com/macros/s/...` 로 시작해요.

### 4단계: 게임에 주소 넣기
1. `index.html`을 열어요.
2. 아래 줄의 `여기에_Apps_Script_웹앱_주소` 부분을 3단계에서 복사한 주소로 바꿔요. 따옴표는 그대로 둬요.
   ```js
   var SCORE_URL = "https://script.google.com/macros/s/....../exec";
   ```

### 5단계: 확인하기
- 게임을 열고 한 판을 끝낸 뒤 이름을 넣어 저장해 보세요. 시트에 한 줄이 생기면 성공이에요.
- 시작 화면의 **점수판 듣기**로 상위 10명을 소리로 들을 수 있어요.

## 알아 둘 점
- **이름은 공개 페이지에 보여요.** 이 저장소가 공개라서, 점수판의 이름도 누구나 볼 수 있어요. 아이들은 별명이나 이니셜로 입력하도록 안내해 주세요.
- **누구나 저장 주소를 알면 점수를 보낼 수 있어요.** 점수 범위(0~100000)와 이름 길이(10자)만 검사해요. 수업용으로 쓰고, 점수판이 이상해지면 시트의 줄을 지우면 돼요.
- 점수 기록은 구글 시트에만 있어요. 게임 페이지 파일에는 들어가지 않아요.
- 스크립트를 고치면 **배포 → 배포 관리 → 새 버전**으로 다시 배포해야 반영돼요. 웹 앱 주소는 바뀌지 않아요.

## GitHub Pages로 공개하기
1. 저장소 **Settings → Pages**에서 Source를 `main` 브랜치의 `/ (root)`로 정해요.
2. 잠시 뒤 `https://lovslave-netizen.github.io/<저장소 이름>/` 주소에서 게임이 열려요.

- `score-server/Code.gs`: 구글 시트 점수판 코드 (Apps Script)
- `README.md`: 이 설명서
